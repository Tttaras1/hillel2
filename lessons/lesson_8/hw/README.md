# Частина 3: відповіді до захисту

## 1. Чому `list.pop(0)` небезпечний для черги?

`pop(0)` видаляє перший елемент списку, після чого Python пересуває решту елементів. Одна така операція потребує **O(n)** часу. Якщо так обробити `n` задач, загальний час може зрости до **O(n²)**.

## 2. Time Complexity, Space Complexity і кешування

**Time Complexity** описує, як зі збільшенням кількості вхідних даних зростає час роботи алгоритму. **Space Complexity** описує, як зростає потрібна йому пам'ять.

Мемоізація зберігає результати попередніх обчислень. Кешування може бути невигідним, коли значення майже не повторюються, результати швидко застарівають або кеш росте без обмеження.

## 3. Закон Амдала

Закон Амдала пояснює, що прискорення однієї частини програми обмежене часом, який займають решта частин. Наприклад, якщо цикл займає лише 10% загального часу, навіть миттєве виконання циклу прискорить програму максимум приблизно на 11%. Тому спершу потрібно виміряти програму й знайти справжнє вузьке місце: ним можуть бути не цикл, а база даних, мережа чи очікування блокування.
