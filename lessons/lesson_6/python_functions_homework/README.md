
Python Functions Homework

This project contains exercises about Python functions.

Functions

verify_int(), verify_float(), verify_number() — check value types.

verify_non_negative() — checks if a number is non-negative.

calculate_total(price, quantity) — calculates the total price.

apply_discount(total, discount_percent=0) — calculates the price after a discount.

calculate_statistics(numbers) — returns the minimum, maximum, and average.

calculate_average(*numbers) — calculates the average of multiple numbers.

create_profile(name, **kwargs) — creates a profile dictionary.

add_product(name, products=None) — adds a product to a list.

Invalid inputs are handled by printing an error message and returning None.

How to Run

python main.py
