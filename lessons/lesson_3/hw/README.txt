
Частина 1. Перевірка теоретичних знань

1. Циклічний алгоритм - послідовність дій яка повтороюється N разів для отримання результату
2. Дискретність - ділення алгоритму на прості послідовні кроки
   Визначенність - кожен этап має бути визначенним і не мати подвійного тлумачення
   Зрозумілість - алгоритм повинен бути зрозумілим для виконавця ( людині якщо це псевдокод або просто послідовність фбо ж компьютеру )
   Кінцевість - алгоритм має мати кінець
   Масовість - алгоритм може масово використовуватись. Є універсальним
   Результативність - має приводити до результату

   Визначеність і кінцевість - важливі для циклічних алгоритмів так як без них алгоритм провалиться в infinite loop
3. For - цикл "ітерації" тобто перебору певного набору значеннь ( літер, індексів, ключів тощо)
   While - цикл котрий виконується поки певна умова ( Умовний цикл )
4. print(range(5)) - (0,1,2,3,4)
   print(range(2, 8)) - (2,3,4,5,6,7)
   print(range(2, 10, 2)) - (2,4,6,8)
   print(range(10, 2, -2)) - (10,8,6,4)

5. Value error - Підозрюю ця помилка оброблюється всередині самого range щоб уникнути infinite loop
6. Infinite loop - Цикл що не має умови виходу або преривання.
   Спричинити може звичайний while True без break, або неправильно написана умов
7. Break - прериває виконання циклу; Continue - іде до некст операції
8 + 9. Else у циклах спрацює за умови якщо не було break; Якщо умова стане False або ітерація ( for ) дійде до останнього елементу
